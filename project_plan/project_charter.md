# Project Charter

> Independent portfolio case study using synthetic data inspired by common photography-business workflows.

## Business problem and objective

Wildlight Portrait Studio is a fictional small business whose booking, revenue, marketing, and payment records are spread across disconnected files. The objective is to create a reproducible reporting system that clarifies performance and identifies opportunities in revenue, marketing efficiency, retention, and administration.

## Scope

In scope: 24 months of synthetic data, validation and cleaning, normalized SQLite analysis, Python and R analyses, an Excel report, BI specifications, recommendations, and reproducible tests. Out of scope: real personal data, live CRM integration, production deployment, and claims that recommendations were implemented.

## Deliverables and success criteria

Deliverables are the repository artifacts documented in the README. Success means scripts run from relative paths, KPI definitions reconcile across outputs, tests pass, data is explicitly synthetic, and a nontechnical reviewer can understand the conclusions.

## Constraints and assumptions

The case study has only two synthetic years, so forecasting is directional. Costs use package variable costs plus operating expenses. A booking is attributed to the lead that preceded it; multi-touch attribution is out of scope.
