# Requirements and Acceptance Criteria

## Functional and data requirements

- Generate the seven synthetic source tables for 24 months with a fixed seed and documented quality defects.
- Standardize sources and dates; resolve duplicate identities, invalid emails, missing package labels, and negative payments without hiding cancellations, reschedules, partial payments, or missing sessions.
- Produce repeatable KPIs, SQL views, separate charts, a basic forecast, dashboard-ready extracts, and a usable Excel workbook.

## Reporting requirements

Report revenue, expenses, profit, margin, conversion, retention, booking outcomes, balances, response time, inquiry-to-booking days, package/source/service performance, growth, and completion. BI guides must provide model, measures, pages, filters, and drill-through ideas.

## Acceptance criteria

All required files are populated; scripts use repository-relative paths; tests pass; workbook formulas contain no obvious errors; key totals reconcile; and every public narrative displays the synthetic-data disclaimer.
