# Open the Power BI project

Open `WildlightAnalytics.pbip` in Power BI Desktop. The semantic model imports the repository's public synthetic analytics CSV and includes canonical DAX measures. The five named report pages are scaffolded for the documented layout. Power BI Desktop is required to render and save a proprietary `.pbix` binary; source-controlled PBIP/PBIR/TMDL files are the editable project source.
